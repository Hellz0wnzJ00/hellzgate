The Platform

Observe. Locate. Log locally.

FullGate brings multiple radios together for wireless research, education, and authorized testing. Its firmware foundation observes Wi-Fi and Bluetooth LE; complete standalone operation is still being verified.

Wireless observation

Passive Wi-Fi observation on 2.4 and 5 GHz, plus Bluetooth LE. One master coordinates nine removable scanner modules.

Local records

GNSS-tagged microSD records verified in separate nine-scanner ESP-NOW and I²C tests. Both saved CSV files were retrieved, checked and accepted in upload tests.

Connected locally

I²C is the primary communication backbone within FullGate. ESP-NOW provides a secondary wireless path. Both transports completed separate nine-scanner FullGate soaks; the earlier 20-scanner bench result is documented below.

Setup & Troubleshooting

Hotspot on demand. One button.

Can't see the HellzGate Wi-Fi network? The hotspot is off after startup in the tested firmware. While the master is running, hold M1's BOOT button for about one second, then release to enable it. Repeat to disable it.

Connect to the dashboard

  • Wi-Fi network / SSID: hellzgate
  • Default password: hellzgate
  • Open http://192.168.4.1 in your browser
  • No internet is expected. Stay connected to use the local dashboard.

Toggle without resetting

  • Use the master's BOOT button, not a scanner's.
  • Do not press RESET or hold BOOT during power-up for this action. BOOT at reset is used for flashing.
  • Hotspot off disconnects the dashboard; scanning and SD logging continue.
  • A restart returns the hotspot to off in the tested builds.

If the SSID is missing, let the master finish booting, hold and release BOOT once, then refresh your Wi-Fi list. Each hold toggles the state; repeated holds can turn it back off. Disabling the hotspot does not disable ESP-NOW or make the device radio-silent. Use Stop on the dashboard to close a logging session before powering down.

Two transports. Real SD files. Successful uploads.

ESP-NOW: 22,645 additional rows reported written, with zero reported lost frames, overflows or restarts. One duplicate frame was detected and discarded.

Wired I²C: 20,550 additional rows reported written across 105,867 additional polls, with zero read errors or wrong IDs. Initial overflow counts did not increase.

Both runs collected BLE and 2.4/5 GHz Wi-Fi observations and held a GNSS fix throughout. Both retrieved SD files had metadata and column headers, and every record had the expected 14 columns.

Saved files, upload results and remaining checks

The ESP-NOW file contained 47,273 records, all accepted by the tested upload service. The I²C file contained 29,102 records; an upload copy removed 63 placeholder timestamps, and all remaining 29,039 records were accepted. File totals include recording outside the timed soak windows. This verifies the tested upload path, not every service.

Display initialization and startup timestamps remain open issues. Complete charging validation and measured field runtime are still pending. Bench results do not establish production readiness or long-term reliability.

Test counters and limitations

The timed window recorded 13,782 frames, no new reported lost frames, overflow, dropouts, or restarts, one new duplicate indication, and zero bad-CRC, bad-field, or table-full errors.

These are timed-window deltas, not cumulative startup counters. All scanners had antennas, but antenna types and observation loads differed. This does not establish maximum RF capacity or complete field performance.

Hardware · Planned Release

The FullGate Core Board.

The first planned HellzGate product is a core board, not a complete ready-to-use kit. No orders or release date announced.

Board design

  • Ten removable XIAO ESP32-C5 module positions: one master and nine scanners
  • Onboard GNSS support and microSD logging
  • USB-C PD input and externally charged 4S lithium-ion battery input through XT60
  • 3.3 V I²C display connector and cooling-fan support

Extended subsystem checks and measured battery runtime remain in progress.

Separate accessories

XIAO modules, antennas, display, fan, power supply, battery, and enclosure are not included with the planned Core Board.

No preorders or waitlists. Availability will be announced on GitHub and Discord after testing.

The Story

One radio was never enough.

HellzGate started with a question: what if a whole cluster of radios could work together and report to one place? A sketch became a breadboard, then custom engineering boards, and now the FullGate design.

V1 and V2 · Retired prototypes

Real boards. Real lessons.

These working engineering platforms helped prove the multi-node concept and expose the power, communication, integration, and mechanical work needed for FullGate.
