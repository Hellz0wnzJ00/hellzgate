# Public technology examples

These small, standalone examples document technologies used during HellzGate development without publishing production firmware, private protocols, device-control logic, or application internals.

- `arduino-c5-board-check/` is an Arduino diagnostic sketch for identifying an ESP32-C5 board and reporting basic memory information.
- `esp-idf-c5-board-check/` provides the equivalent diagnostic in C using ESP-IDF.
- `flutter-node-model/` demonstrates a small Dart model suitable for presenting node status in a Flutter interface.

They are reference examples only. They are not the HellzGate production firmware or companion application.
